## Project Setup

### 1. Clone the project and submodules:

```bash
git clone https://github.com/sangafabrice/minify-kit-dev . --recurse-submodules
```

### 2. Install the packages:

```bash
npm install
```

### 4. Disable JavaScript validation in VS Code:
